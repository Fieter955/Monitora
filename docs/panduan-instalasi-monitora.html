1 Instalasi Server Monitoring Utama (Linux)

Server pusat ini menjalankan seluruh layanan inti Monitora (Next.js, FastAPI, PostgreSQL, Prometheus, Grafana) menggunakan Docker Compose.

Langkah 1.1: Pastikan Docker & Git Terpasang
sudo apt update && sudo apt install -y docker.io docker-compose-v2 git
Langkah 1.2: Masuk ke Folder Project & Siapkan Konfigurasi .env
cd /opt/Monitora
cp .env.example .env
Langkah 1.3: Jalankan Stack Monitoring
docker compose up -d --build
docker compose ps
Aplikasi web Monitora kini sudah aktif pada: http://192.168.1.10:8080 (Login default: admin / admin12345).

2 Instalasi Agen di Linux Client (Target Linux)

Pada mesin Linux target yang akan dipantau (IP: 192.168.1.20), pasang Node Exporter untuk metrik CPU, RAM, Disk, dan Jaringan.

Langkah 2.1: Unduh & Pasang Binary Node Exporter
wget https://github.com/prometheus/node_exporter/releases/download/v1.9.0/node_exporter-1.9.0.linux-amd64.tar.gz
tar -xvf node_exporter-1.9.0.linux-amd64.tar.gz
sudo mv node_exporter-1.9.0.linux-amd64/node_exporter /usr/local/bin/
sudo useradd -rs /bin/false node_exporter
Langkah 2.2: Buat Service Systemd Otomatis
sudo tee /etc/systemd/system/node_exporter.service <
Langkah 2.3: Buka Firewall Port 9100 & Verifikasi
# Izinkan port 9100 khusus dari IP Server Monitoring
sudo ufw allow proto tcp from 192.168.1.10 to any port 9100

# Verifikasi lokal:
curl http://localhost:9100/metrics

3 Instalasi Agen di Windows Client (Target Windows)

Pada mesin Windows target (IP: 192.168.1.30), pasang agen Windows Exporter (port default 9182).

Langkah 3.1: Buka PowerShell sebagai Administrator
  1. Klik menu Start di Windows target, ketik PowerShell.
  2. Klik kanan pada Windows PowerShell lalu klik "Run as administrator".
Langkah 3.2: Eksekusi Script Instalasi Satu Klik

Salin dan tempel perintah berikut di PowerShell (sesuaikan $MonitoringServer ke IP server monitoring):

$MonitoringServer = "192.168.1.10"
$Version = "0.31.8"
$Url = "https://github.com/prometheus-community/windows_exporter/releases/download/v$Version/windows_exporter-$Version-amd64.msi"
$OutFile = "$env:TEMP\windows_exporter.msi"

Write-Host "1. Mengunduh windows_exporter..."
Invoke-WebRequest -Uri $Url -OutFile $OutFile

Write-Host "2. Memasang service windows_exporter..."
$args = @("/i", $OutFile, "/qn", "/norestart", "ENABLED_COLLECTORS=cpu,logical_disk,memory,net,os,service,system", "LISTEN_PORT=9182")
Start-Process msiexec.exe -ArgumentList $args -Wait

Write-Host "3. Membuka port firewall 9182 untuk Server Monitoring..."
Get-NetFirewallRule -DisplayName "Monitora windows_exporter" -ErrorAction SilentlyContinue | Remove-NetFirewallRule
New-NetFirewallRule -DisplayName "Monitora windows_exporter" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 9182 -RemoteAddress $MonitoringServer | Out-Null

Write-Host "SELESAI! windows_exporter aktif pada port 9182."

*Aturan firewall otomatis mengizinkan port 9182 hanya dari IP Server Monitoring (192.168.1.10).

Langkah 3.3: Uji Verifikasi Agen Windows

Ketik perintah verifikasi berikut di PowerShell:

Invoke-WebRequest -Uri http://localhost:9182/metrics

Jika output menghasilkan StatusCode : 200, agen Windows sudah berjalan dengan benar dan siap dihubungkan ke Monitora.

Cek Status Service Windows (Jika Diperlukan)

Untuk memastikan service berjalan di latar belakang kapan saja:

Get-Service windows_exporter

Pastikan statusnya Running.

5 Melihat Hasil & Grafik Performa di Grafana

Alur Pemantauan Grafik
  1. Setelah perangkat disimpan, perangkat akan muncul di tabel Perangkat dengan status badge hijau Aktif.
  2. Prometheus melakukan penarikan (*scrape*) berkala setiap 15–30 detik.
  3. Untuk melihat grafik performa (CPU, RAM, Disk, Traffic Jaringan):
    • Di bilah navigasi kiri paling bawah, klik tombol "Buka Grafana".
    • Grafana akan terbuka di tab baru. Pilih dashboard sesuai jenis perangkat:
      • Server Linux → untuk melihat metrik CPU, memori, disk, dan interface server Linux.
      • Server Windows → untuk melihat metrik CPU usage, physical memory, logical disk, dan network server Windows.

6 Panduan Troubleshooting Masalah Umum

1. Target Berstatus "Down" atau Merah di Prometheus
  • Port Terblokir Firewall Target: Pastikan port 9100 (Linux) atau 9182 (Windows) sudah diizinkan untuk menerima koneksi dari IP Server Monitoring (192.168.1.10).
  • Penulisan Target Tanpa Port: Pada kolom Target monitoring aplikasi Monitora, wajib menyertakan port: 192.168.1.20:9100 atau 192.168.1.30:9182. Jika hanya menulis IP tanpa port, scrape Prometheus akan gagal.
2. Uji Koneksi Langsung dari Server Monitoring (Terminal Linux Utama)

Jika ragu apakah server monitoring bisa menjangkau target, jalankan perintah uji ini dari server utama:

# Uji ke Linux Client:
curl -m 5 http://192.168.1.20:9100/metrics

# Uji ke Windows Client:
curl -m 5 http://192.168.1.30:9182/metrics

Jika muncul respon teks metrik, koneksi jaringan dan agen di mesin target dipastikan 100% normal.

3. Verifikasi Status Target di Prometheus Web UI

Buka http://192.168.1.10:9090/targets di browser. Periksa job node dan windows. Target yang sehat akan menampilkan tanda hijau UP.
